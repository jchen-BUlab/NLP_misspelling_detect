Using specialized transformer models and general-purpose large language models (e.g., GPT-4o) to detect misspelled medication names to support clinical research and improve the quality of medication databases. Code developed for the NLP Misspelling Detection project and the 2026 paper accepted by JMIR Medical Informatics.

Lu J, McConeghy K, Zullo A, Chen J. Detecting Misspelled Drug Names Using Transformer-based Language Models. Accepted by JMIR Medical Informatics.
